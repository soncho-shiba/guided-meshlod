Building the native binary
---------------------------
Both build scripts clone the upstream repo at the pinned commit into a
temp directory, build with cmake, copy the output next to this version.txt,
then clean up. Run from inside this folder.

  Windows 11 x64:        pwsh ./build_windows.ps1     (or PowerShell 5.1)
  macOS 11+ universal:   bash ./build_macos.sh

Both scripts require: git, cmake. macOS additionally requires Xcode CLT.
The Windows DLL and macOS bundle/dylib are committed alongside the script,
so first-time clones on either platform have a working binary already.
